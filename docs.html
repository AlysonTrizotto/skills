Como instalar, configurar e estender o ecossistema Staff+.

Instalação e Comandos CLI

Copie a pasta staff-plus-skills para a raiz do seu repositório e utilize os comandos abaixo:

./install.sh            # Instala / Atualiza todas as regras nas IDEs
./install.sh --update   # Sincroniza regras e limpa skills órfãs (.claude/skills/)
./install.sh --verify   # Valida esquemas YAML, seções e o roteador AGENTS.md
./install.sh --git-hook # Instala hook pre-commit para validação automática
./install.sh --package  # Gera o pacote comercial zip para distribuição

O Router: AGENTS.md e o Protocolo de Auto-Correção

Ao rodar a instalação, o arquivo AGENTS.md é depositado na raiz do repositório como o roteador universal. Ele injeta o Self-Correction Protocol, forçando o agente de IA a validar silenciosamente todo diff de código contra a Review Checklist da skill ativa antes de exibir a solução final.

Catálogo de 16 Skills Inclusas

O pacote inclui 16 personas especialistas em backends, frontends, mobile, DevOps, QA, arquitetura e engenharia:

  • architecture-staff: Arquitetura de Sistemas, DDD, Event-Driven Architecture, Outbox Pattern e ADRs.
  • engineering-excellence: Software Craftsmanship, SOLID, observabilidade com OpenTelemetry e migrações zero-downtime.
  • code-review-backend: Review rigoroso de backend (N+1, SQL perf, Idempotência, concorrência).
  • code-review-frontend: Review de Web Vitals (LCP/CLS/INP), isolamento de re-renders e acessibilidade WCAG AA.
  • code-review-mobile: Review de UI thread jank, memory leaks nativos, consumo de bateria e sync offline.
  • backend-node: Event loop, streams, async safety e graceful shutdown.
  • backend-fastapi / backend-django / backend-flask / backend-laravel / backend-hyperf / backend-rails: Regras profundas para cada ecossistema.
  • devops-lean & qa-api-destroyer: SRE, infra imutável, idempotência e testes adversariais agressivos.

Compatibilidade

As skills rodam através dos protocolos nativos das principais ferramentas corporativas de IA:

  • Claude Code: Injetado como tools (`.claude/skills`).
  • Cursor: Injetado como regras globais (MDC).
  • Windsurf: Integrado de forma invisível via `.windsurfrules`.
  • Antigravity: Lê o `AGENTS.md` de forma completamente nativa.
