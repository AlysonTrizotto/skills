Documentação

Como instalar, configurar e estender o ecossistema Staff+.

Instalação Universal (30 segundos)

A forma mais rápida de injetar a inteligência no seu projeto é utilizando o nosso script instalador. Copie a pasta staff-plus-skills para a raiz do seu repositório e rode:

cp -r staff-plus-skills/ /caminho/do/seu/repo/
cd /caminho/do/seu/repo
./staff-plus-skills/install.sh

O Router: AGENTS.md

Ao rodar a instalação, o arquivo AGENTS.md será depositado na raiz do seu repositório. Ele é o coração do sistema. Diferente de regras engessadas, ele detecta manifestos como package.json ou pyproject.toml para carregar a skill apropriada magicamente.

Skills Inclusas no Pacote

O pacote base acompanha personas focadas nos ecossistemas mais populares e desafios arquiteturais avançados:

  • backend-django: Otimização de ORM, proteção contra vazamento em serializers DRF.
  • backend-flask: Isolamento de dependências via Application Factory.
  • backend-fastapi: Injeção de dependências e validação estrita com Pydantic na borda.
  • backend-node: Disciplina no Event Loop, proteção contra travamentos síncronos e Memory Leaks.
  • backend-laravel: Uso idiomático de coleções e padronização arquitetural cache-first.
  • devops-lean & qa-api-destroyer: Skills transversais que ativam por intenção da tarefa, blindando CI/CD e testes agressivos.

Compatibilidade

As skills rodam através dos protocolos nativos das principais ferramentas corporativas de IA:

  • Claude Code: Injetado como tools (`.claude/skills`).
  • Cursor: Injetado como regras globais (MDC).
  • Windsurf: Integrado de forma invisível via `.windsurfrules`.
  • Antigravity: Lê o `AGENTS.md` de forma completamente nativa.
