# 🚀 Full-Cycle Staff+ AI Rules

Transforme sua IDE em um parceiro de engenharia nível Staff+. Este pacote contém regras de contexto rigorosas, focadas em alta performance, resiliência e pragmatismo.

## 🛠️ Como usar (Instalação em 30 segundos)

1. **Escolha o seu ecossistema:** Navegue pelos arquivos do pacote e encontre a regra que corresponde à stack ou ao domínio do seu projeto (ex: `backend_laravel.rules`, `frontend_performance.rules`, `devops_lean.rules`).
2. **Copie para a raiz do projeto:** Cole o arquivo escolhido na **pasta raiz** do seu repositório.
3. **Renomeie o arquivo:** O nome exato ativa a leitura automática pela IDE:
   - Se você utiliza o **Windsurf AI Desktop IDE**: renomeie o arquivo para `.windsurfrules`
   - Se você utiliza o **Cursor**: renomeie o arquivo para `.cursorrules`
4. **Pronto!** A partir de agora, qualquer prompt ou chat gerado na IDE vai respeitar essas diretrizes arquiteturais de forma autônoma. 

*Dica pro:* Mantenha o arquivo versionado no seu repositório (`git add`) para que toda a sua equipe herde o mesmo nível de exigência técnica nas interações com a IA.
